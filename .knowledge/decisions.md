# Decisions

- 2026-10-17 No code from custom-glow-enchantment-outline: All Rights Reserved.
- 2026-10-17 Model gap fix reimplemented from the technique, not copied: upstream is GPL-3.0 and we ship MIT.
- 2026-10-17 No textures from the Rainbow Enchantment Glint pack: no licence. Glint presets are generated by our own code.
- 2026-10-17 Outlines are computed from the item's real rendered geometry, not per-item models or whitelists: owner requires universal support for all mods.
- 2026-10-17 Name Glintsmith: free on Modrinth, says what the mod does.
- 2026-10-17 Stack copied from DynamicLighting (Loom remap plugin, mojmap, Java 21, Gradle 9.5.0): proven in this workspace with the same pack versions.
- 2026-10-17 GitHub repo public from the first push: owner confirmed the defaults in chat.
- 2026-10-17 Outline condition ENCHANTED also counts foil items (enchanted golden apple etc.): matches what players see as enchanted.
- 2026-10-17 Keybinds unbound by default; /glintsmith command and Mod Menu open the screen: avoids key conflicts in modpacks.
- 2026-10-17 Parallel cap raised to up to 4 Sonnet + 2 Opus: owner allowed more parallel agents; files stay disjoint.
- 2026-10-17 Gap fix AUTO mode turns itself off when the `modelfix` mod is loaded (the Nytheria pack ships it): two seam fixes on the same models would stack.
- 2026-10-17 The Nytheria project is not modified by this session. How to run the in-game test with the broken harness is decided at T10 (owner question if needed). After any run, remove `config/glintsmith.json` and `config/glintsmith/` from the pack instance.
- 2026-10-17 T5 runs in a git worktree `../Glintsmith-t5` (branch `t5-outline`), merged into dev by the lead after review: its partial GL code must not break T6 builds in the main tree.
- 2026-10-17 T10 harness: shadow copy of the harness in the session scratchpad (launcher files restored from git), Nytheria project untouched.
- 2026-10-17 Gallery images are real in-game captures of the mod, framed like the Lootr cards; hand-drawn pixel-art cards and banner dropped: owner rejected them as fake and ugly.
- 2026-10-17 Vanilla font/textures are read from the Minecraft jar at image build time and never committed: same practice as the Obscura preview tools.
- 2026-10-17 Raw in-game captures (`art/captures/**`) stay local and git-ignored; only the composed gallery images are committed: 38 stills + 280 GIF frames would add several hundred MB to the repo.
- 2026-10-17 Owner: no pixel art anywhere, real renders only (method left to the lead). Logo, icon, banner hero, cards and GIF all come from in-game renders of the mod (narrow-FOV hero close-ups on a dark backdrop); the hand-drawn logo committed in a816b40 is replaced. No Blender: not installed, and a download is not needed.
- 2026-10-17 fabric.mod.json depends on minecraft "1.21.1" exactly (not ~1.21.1): mixins target 1.21.1 internals; 1.21.2+ changed rendering.
- 2026-10-17 T9 docs drafted before the in-game test with VERIFY IN GAME markers; a final pass removes them after T10: saves wall-clock time, claims stay checked.
- 2026-10-17 Gap-fix mixins that collide with modelfix are not applied when modelfix is loaded (IMixinConfigPlugin): Mixin cannot inject into a method another mod merged, and the pack ships modelfix.
- 2026-10-17 Owner: modelfix removed from the Nytheria pack, Glintsmith's own gap fix (AUTO) takes over there. Jar moved (not deleted) to .dev/removed-mods/; instance repo not committed, CurseForge manifest not edited. The modelfix compat plugin stays: the public mod must not crash in other packs with modelfix.
- 2026-10-17 Owner: no outline on worn armor by default; the armor target (also covers worn elytra) defaults to off and stays a config/screen option.
- 2026-10-17 Gap fix keeps vanilla's corner order of side elements (no sorting): vanilla stores LEFT/RIGHT spans with from.y > to.y on purpose and FaceBakery derives winding from that order.
- 2026-10-17 In the HAND phase the phase, not the display context, decides the target: first-person animation mods (Punchy) draw held items with third-person contexts inside renderHandsWithItems.
- 2026-10-17 AUTO gap fix (non-macOS) uses sideExpansion 0.005: in-game sweep closed the remaining step-corner cracks at 0.005; 0.01+ showed slivers. macOS values unchanged (not verifiable here).
- 2026-10-17 CUSTOM gap-fix stored default sideExpansion mirrors AUTO non-macOS (0.005): switching AUTO -> CUSTOM must not bring the corner cracks back.
- 2026-10-17 Optional perf work (5.5) dropped: the no-mod baseline varies ±20 % between identical windows, larger than any measured outline cost.
- 2026-10-17 Outline mask stores the item's own depth and only visible item pixels seed the outline (hand front tolerance 0.03 blocks): hidden item pixels (blade inside the arm, item leaning on a pillar) drew outlines over the occluder.
- 2026-10-17 Gallery/logo backdrop switched from black to white/cream (owner request); capture rooms use light blocks + night vision + gamma Bright; close-ups use the vanilla FOV option 30 because the Director fov override does not change the world view.
