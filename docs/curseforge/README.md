# CurseForge page material for Glintsmith

| File | What |
|---|---|
| `description.md` | The project description (Markdown), with one paste marker line for each image and HTML comments for claims that are not final yet (at the moment there are none) |
| `summary.txt` | The short summary for the project form (one line, at most 250 characters) |
| `upload-checklist.md` | The fields of the CurseForge forms and what to enter |
| `preview.html` | The description with the images inline, for a browser; works offline when opened from this folder |
| `description_paste.md` | `description.md` without the HTML comments; this is the text to paste. Generated, do not edit |
| `preview.py` | Writes `preview.html` and `description_paste.md`, and checks the markers |
| `img/` | The gallery images the description refers to. Generated by the art pipeline (`art/`), not by hand |

## Images

The image names are the `out` fields of `art/gallery/cards.json`. They are composed from real renders of the mod: studio
turntables and stills of the dev-only studio (`docs/STUDIO.md`) and in-game screenshots (`art/README.md`,
`art/gallery/SHOTLIST.md`); this folder only refers to them.

| File | What it shows |
|---|---|
| `banner.png` | Title banner: a studio render of the sword, name, tagline and three chips |
| `showcase.gif` | The studio turntable of one sword cycling through its looks (outline colours, glint presets), captioned, 512 px, at most 8 MB |
| `lineup.gif` | Six items in a row, each with its own glint and outline, swinging, captioned, at most 8 MB. Next to `card_universal.png` |

## Putting the description on CurseForge

1. Remove the HTML comments, or use `description_paste.md`, which already has none. Do this only after every comment has been resolved and the text has been corrected where it was wrong.
2. Open the project's description editor, switch to the Markdown editor and paste the content.
3. At every line that reads `>>> PASTE IMAGE: file_name.png | Alt text <<<`, upload `img/file_name.png` with the editor's image button, use the text after the `|` as the alt text, and delete the marker line.
4. Check the preview. The comparison is a Markdown table; if the editor does not render tables, rebuild it in the rich text editor or replace it with a list.
5. Upload the images as they are and do not let the site rescale them.

## Rebuilding

```
py -B docs\curseforge\preview.py            write preview.html and description_paste.md
py -B docs\curseforge\preview.py --check    verify
```

`--check` verifies that every marker line has the exact form, names an existing file in `img/` and is used once, that
`summary.txt` is one line of at most 250 characters, and that `preview.html` and `description_paste.md` are up to date.
An image that is a build output of the art pipeline (an `out` of `art/gallery/cards.json`) and has not been built yet is
reported as a NOTE, not a problem; `--strict` makes it a problem. Build the images with `py -B art/gallery/build.py`
(see `art/README.md`) before uploading.
